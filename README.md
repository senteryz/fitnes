# Фитнес-центр «Аура» — GitHub Pages Edition

Статическая версия сайта, готовая к размещению на **GitHub Pages** с базой данных на **GitHub REST API**.

---

## 🚀 Особенности этой сборки:
1. **Никаких серверов и платных баз данных:**
   - Сайт работает на 100% бесплатно на GitHub Pages.
   - Данные клуба, цены, тренеры, отзывы, новости, галерея и расписание хранятся в `data/db.json`.

2. **Клиентская панель управления (`admin.html`):**
   - Работает прямо в браузере.
   - Для сохранения изменений используется **GitHub Personal Access Token (PAT)**.
   - Любое изменение в админке автоматически коммитится в репозиторий через GitHub REST API!
   - Загрузка фотографий конвертирует файлы в оптимизированный Base64 через браузерный `FileReader`.

3. **Всплывающее окно акции (Pop-up):**
   - Появляется на главной странице через 2.5 сек для новых посетителей.
   - Управляется из админки (вкладка «Всплывающая акция»).

## 🛠 Как включить на GitHub Pages:

### Способ А: Через ветку `gh-pages` (Рекомендуется)
1. Закоммитьте содержимое этой папки в ветку `gh-pages`:
   ```bash
   git checkout -b gh-pages
   # скопируйте файлы этой папки в корень ветки
   git add .
   git commit -m "Deploy to GitHub Pages"
   git push origin gh-pages
   ```
2. В GitHub перейдите в **Settings** → **Pages** → выберите ветку **`gh-pages`** и папку **`/ (root)`**.
3. Сайт станет доступен по адресу: `https://senteryz.github.io/fitnes/`

### Способ Б: Как отдельный репозиторий
1. Создайте новый репозиторий на GitHub.
2. Инициализируйте git внутри папки `gh-pages` и сделайте push.
3. В настройках репозитория включите GitHub Pages на ветке `main`.
